Terminal task board · deliberate practice

Track what you study.
Get coached through it.
See proof you improved.

A terminal practice system for interview and skill prep — one keyboard-driven session instead of a to-do app, a study guide, an AI chat tab, and a code sandbox stitched together by hand. Task, coach, AI, and music all live in the same window on purpose: what actually breaks focus is switching screens, not the studying itself.

What's inside

Eight tools. One session.

$ boardkanban

Kanban Board

Backlog → Todo → In Progress → Done — one column per field you track, prefilled from a real curriculum, not a blank list.

$ focusfocus mode

Focus Mode

One key hides the board and stats, auto-starts a 45/10 pomodoro, and surfaces only the coach and AI panel for whatever you're on.

$ coach dsalearning coach

Learning Coach

Generates a real DSA or SQL problem for whatever's in progress, then rations hints one at a time instead of handing you the answer.

$ lab pythonpractice lab

Practice Lab

Real execution — Python, Java, C, C++, SQL — against a real sqlite3 database, linked to whatever the coach just generated.

$ ai …ai assistant

AI Assistant

An embedded panel that already knows the task, field, and problem you're on — instructed once to teach with questions, not hand over the fix.

you › why is my query slow

mtdo-ai › what's making that comparison expensive on every row?

$ crmcareer crm

Career CRM

Applied → OA → Interview → Offer — one pipeline for every application, wired up automatically by the setup wizard for a job-switch or college plan.

Razorpay · SDE1

Applied → OA → [Interview] → Offer

$ vaultknowledge vault

Knowledge Vault

A second brain, separate from any one task — searchable notes on system design, behavioral prep, SQL internals, whatever you've picked up.

System design: rate limiter

token bucket vs sliding window

$ keyspomodoro + streaks

Pomodoro & Streaks

A 45/10 pomodoro auto-starts with Focus Mode; streaks and a GitHub-style heatmap track whether you actually showed up.

p/x start-pause · reset

m play/pause · [ / ] prev/next track

$ musiclock in

Music, Without Leaving

Universal now-playing controls for whatever's already going — YouTube Music in a tab, Apple Music, Spotify, anything — plus paste a Spotify link to jump straight there. Lives inside Focus Mode so you never alt-tab to hit pause.

$ youtube …no rabbit holes

YouTube → Notes & Quiz

Paste a tutorial link — the AI turns its captions into study notes plus 5–8 active-recall questions, saved to the Vault and yours to edit. Built for the habit of rewatching three videos and assuming you understood the first one.

Get it running

$ install

Recommended — handles prerequisites for you

$ git clone https://github.com/mukund1312/mtdo.git
$ cd mtdo
$ ./install.sh

checks git, Python 3.10+, sqlite3 (and Xcode Command Line Tools on macOS) up front, with a specific fix for whichever's missing — and sets up its own .venv rather than touching your system Python.

Already have everything installed

$ pip install -e .

from a clone of the repo, then just run mtdo — first run auto-creates ~/.mtdo/config.yaml from the demo plan.
